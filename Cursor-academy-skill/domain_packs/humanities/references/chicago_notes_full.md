# Chicago Notes-Bibliography Style Checklist

## Notes System (Footnotes / Endnotes)
- [ ] First citations of any work MUST include full bibliographical details in the footnote.
- [ ] Subsequent citations of the same work in footnotes MUST use shortened citations (Author, shortened title, page).
- [ ] "Ibid." should be avoided or used with caution per recent CMS revisions; prefer shortened citations.
- [ ] Footnote numbers should be superscripts in the text, placed at the end of a clause or sentence.
- [ ] Footnote numbers must follow all punctuation marks, including closing quotation marks and parentheses.

## Bibliography
- [ ] Sorted alphabetically by author's family name.
- [ ] Author names inverted for the first author (Family Name, Given Name).
- [ ] Subsequent author names in the same entry are presented in standard order (Given Name Family Name).
- [ ] Title of books and journals are italicized.
- [ ] Title of articles and chapters are placed inside quotation marks.
- [ ] Hang indentation used for each entry.
- [ ] Publisher, place of publication, and year included for books.
